Integration Notes

In test mode

  • Pick one of the test institutions Stripe lists; each one shows what it simulates
  • The session only links US accounts (filters[country]=US)

After linking

  1. Run the script again with the session ID to read the accounts, balance and transactions
  2. Your backend gets financial_connections.account.created per account (FinancialConnections.processEvent)
  3. Refreshes are asynchronous: wait for refreshed_balance / refreshed_transactions
