Direct Debit Setup

1. Load the setup intent

Run dotnet fsi examples/DirectDebit.fsx and paste the setup intent's client secret it prints.

2. Enter the bank details and accept the mandate

The Payment Element shows the fields and the mandate text of the scheme the setup intent allows.

Integration Notes

Test bank details

  • SEPA, succeeds: IBAN DE89370400440532013000
  • SEPA, debit fails: IBAN DE62370400440532013001
  • Bacs: sort code 108800, account 00012345
  • BECS: BSB 000000, account 000123456
  • ACH: pick a test bank in the Financial Connections dialog

After the setup

  1. setup_intent.succeeded gives you the payment method and mandate to store (DirectDebit.processEvent)
  2. Charge it off-session with DirectDebit.chargeSavedAccount
  3. The debit is processing for days; fulfil on payment_intent.succeeded
